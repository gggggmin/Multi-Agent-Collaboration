# 登录模块需求文档

## 功能1：用户登录（正向）
- **前置条件**：用户已注册（测试账号 testuser/password123）
- **操作路径**：访问登录页 → 输入用户名 → 输入密码 → 点击登录按钮
- **预期结果**：登录成功，跳转首页，右上角显示用户昵称
- **类型**：正向

## 功能2：登录失败-错误密码
- **前置条件**：用户已注册
- **操作路径**：访问登录页 → 输入正确用户名 → 输入错误密码 → 点击登录按钮
- **预期结果**：页面刷新，提示"用户名或密码错误"，停留在登录页
- **类型**：逆向

## 功能3：登录失败-空用户名
- **前置条件**：无
- **操作路径**：访问登录页 → 不输入用户名 → 输入任意密码 → 点击登录按钮
- **预期结果**：提示"用户名和密码不能为空"，停留在登录页
- **类型**：边界值

## 功能4：登录失败-空密码
- **前置条件**：无
- **操作路径**：访问登录页 → 输入任意用户名 → 不输入密码 → 点击登录按钮
- **预期结果**：提示"用户名和密码不能为空"，停留在登录页
- **类型**：边界值

## 功能5：登录失败-空用户名和空密码
- **前置条件**：无
- **操作路径**：访问登录页 → 不输入用户名 → 不输入密码 → 点击登录按钮
- **预期结果**：提示"用户名和密码不能为空"，停留在登录页
- **类型**：边界值

## 功能6：登录失败-不存在的用户
- **前置条件**：无
- **操作路径**：访问登录页 → 输入不存在的用户名 → 输入任意密码 → 点击登录按钮
- **预期结果**：提示"用户名或密码错误"，停留在登录页
- **类型**：逆向

## 功能7：登出
- **前置条件**：用户已登录
- **操作路径**：点击右上角"退出"链接
- **预期结果**：跳转首页，提示"已安全退出"，导航栏显示"登录"按钮
- **类型**：正向

## 功能8：未登录访问购物车
- **前置条件**：未登录
- **操作路径**：直接访问 /cart
- **预期结果**：可以访问购物车页面，购物车为空
- **类型**：边界值

## 功能9：未登录访问结算页
- **前置条件**：未登录
- **操作路径**：直接访问 /checkout
- **预期结果**：跳转登录页，提示"请先登录后再下单"
- **类型**：逆向

## 功能10：登录后保持会话
- **前置条件**：用户已登录
- **操作路径**：登录 → 访问首页 → 访问购物车 → 访问结算页
- **预期结果**：所有页面都保持登录状态，显示用户昵称
- **类型**：正向

## 功能11：已登录用户重复登录
- **前置条件**：用户已登录
- **操作路径**：已登录状态下访问 /login 页面
- **预期结果**：显示登录页面（Flask默认行为，新会话）
- **类型**：边界值

## 功能12：管理员账号登录
- **前置条件**：管理员账号已存在（admin/admin123）
- **操作路径**：访问登录页 → 输入管理员用户名 → 输入管理员密码 → 点击登录按钮
- **预期结果**：登录成功，跳转首页，显示管理员用户名
- **类型**：正向

## 功能13：密码大小写错误
- **前置条件**：用户已注册
- **操作路径**：访问登录页 → 输入用户名 testuser → 输入大小写不匹配的密码 → 点击登录按钮
- **预期结果**：提示"用户名或密码错误"，停留在登录页
- **类型**：逆向

## 功能14：用户名大小写错误
- **前置条件**：用户已注册
- **操作路径**：访问登录页 → 输入大小写不匹配的用户名 → 输入正确密码 → 点击登录按钮
- **预期结果**：提示"用户名或密码错误"，停留在登录页
- **类型**：逆向

## 功能15：登录页初始展示
- **前置条件**：未登录
- **操作路径**：访问 /login 页面
- **预期结果**：显示用户名输入框、密码输入框和登录按钮
- **类型**：正向

## 功能16：登出后访问结算页
- **前置条件**：用户已登录
- **操作路径**：点击退出 → 直接访问 /checkout
- **预期结果**：跳转登录页，提示"请先登录后再下单"
- **类型**：逆向

## 功能17：admin错误密码登录
- **前置条件**：管理员账号已存在
- **操作路径**：访问登录页 → 输入用户名 admin → 输入错误密码 → 点击登录
- **预期结果**：提示"用户名或密码错误"，停留在登录页
- **类型**：逆向

## 功能18：登录后首页显示用户名
- **前置条件**：用户已登录
- **操作路径**：登录成功后访问首页
- **预期结果**：首页导航区域显示 testuser
- **类型**：正向

## 功能19：登录失败后仍可重新登录
- **前置条件**：用户已注册
- **操作路径**：先输入错误密码登录失败 → 再输入正确密码登录
- **预期结果**：第二次登录成功，跳转首页
- **类型**：正向

## 功能20：登出后首页不显示用户名
- **前置条件**：用户已登录
- **操作路径**：点击退出后返回首页
- **预期结果**：首页不再显示 testuser，显示登录入口
- **类型**：正向

## 功能21：登录表单必填字段
- **前置条件**：未登录
- **操作路径**：访问登录页
- **预期结果**：用户名和密码输入框均具备必填约束
- **类型**：边界值
