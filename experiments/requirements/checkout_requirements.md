# 下单结算模块需求文档

## 功能1：正常下单结算（正向）
- **前置条件**：用户已登录，购物车中有商品
- **操作路径**：购物车 → 点击"去结算" → 填写收货地址 → 选择支付方式 → 点击"提交订单"
- **预期结果**：订单提交成功，显示订单号和商品清单
- **类型**：正向

## 功能2：未登录访问结算页
- **前置条件**：未登录状态，购物车中有商品
- **操作路径**：直接访问 /checkout
- **预期结果**：跳转登录页，提示"请先登录后再下单"
- **类型**：逆向

## 功能3：空购物车结算
- **前置条件**：用户已登录，购物车为空
- **操作路径**：直接访问 /checkout
- **预期结果**：跳转购物车页，提示"购物车为空，请先添加商品"
- **类型**：边界值

## 功能4：结算时不填写收货地址
- **前置条件**：用户已登录，购物车中有商品
- **操作路径**：购物车 → 点击"去结算" → 不填写地址 → 点击"提交订单"
- **预期结果**：提示"请填写收货地址"，停留在结算页
- **类型**：边界值

## 功能5：选择不同支付方式
- **前置条件**：用户已登录，购物车中有商品
- **操作路径**：结算页 → 填写地址 → 分别选择"微信支付"/"支付宝"/"银行卡" → 提交订单
- **预期结果**：每种支付方式均可成功提交订单
- **类型**：正向

## 功能6：查看订单详情
- **前置条件**：用户已登录，有已提交的订单
- **操作路径**：订单提交成功后 → 查看订单详情页
- **预期结果**：显示订单号、商品清单、收货地址、支付方式、订单状态、下单时间
- **类型**：正向

## 功能7：未登录查看订单
- **前置条件**：未登录
- **操作路径**：直接访问 /order/<order_id>
- **预期结果**：跳转登录页，提示"请先登录"
- **类型**：逆向

## 功能8：登录后商品库存扣减
- **前置条件**：用户已登录，购物车中有商品
- **操作路径**：正常下单 → 提交订单 → 查看首页对应商品库存
- **预期结果**：下单成功后，对应商品库存减少
- **类型**：正向

## 功能9：多次下单同一商品（库存耗尽）
- **前置条件**：用户已登录，商品库存有限
- **操作路径**：将某商品全部加入购物车 → 下单 → 再次尝试将同商品加入购物车
- **预期结果**：第一次下单成功，第二次提示"库存不足"
- **类型**：边界值

## 功能10：未登录访问订单详情（不存在订单）
- **前置条件**：未登录
- **操作路径**：直接访问 /order/nonexistent
- **预期结果**：跳转登录页，提示"请先登录"
- **类型**：逆向

## 功能11：结算时商品刚好有货
- **前置条件**：用户已登录，商品库存刚好等于购物车数量
- **操作路径**：将库存全部加入购物车 → 提交订单
- **预期结果**：订单提交成功，扣减后库存为0
- **类型**：边界值

## 功能12：银行卡支付下单
- **前置条件**：用户已登录，购物车中有商品
- **操作路径**：结算页填写地址 → 支付方式选择"银行卡" → 提交订单
- **预期结果**：订单提交成功，订单详情显示银行卡
- **类型**：正向

## 功能13：已登录访问不存在订单
- **前置条件**：用户已登录
- **操作路径**：访问 /order/non-existent-order
- **预期结果**：跳转首页，提示"订单不存在"
- **类型**：逆向

## 功能14：提交订单后购物车清空
- **前置条件**：用户已登录，购物车中有商品
- **操作路径**：正常提交订单 → 再访问购物车
- **预期结果**：购物车为空
- **类型**：正向

## 功能15：结算页展示商品清单
- **前置条件**：用户已登录，购物车中有商品
- **操作路径**：进入结算页
- **预期结果**：显示商品名称、数量和总价
- **类型**：正向

## 功能16：地址前后空格处理
- **前置条件**：用户已登录，购物车中有商品
- **操作路径**：地址输入前后带空格的文本 → 提交订单
- **预期结果**：订单提交成功，地址按有效内容展示
- **类型**：边界值

## 功能17：支付宝支付下单
- **前置条件**：用户已登录，购物车中有商品
- **操作路径**：结算页填写地址 → 支付方式选择"支付宝" → 提交订单
- **预期结果**：订单提交成功，订单详情显示支付宝
- **类型**：正向

## 功能18：微信支付下单
- **前置条件**：用户已登录，购物车中有商品
- **操作路径**：结算页填写地址 → 支付方式选择"微信支付" → 提交订单
- **预期结果**：订单提交成功，订单详情显示微信支付
- **类型**：正向

## 功能19：订单详情显示订单状态
- **前置条件**：用户已登录并已下单
- **操作路径**：访问订单详情页
- **预期结果**：显示订单状态 pending
- **类型**：正向

## 功能20：订单详情显示下单时间
- **前置条件**：用户已登录并已下单
- **操作路径**：访问订单详情页
- **预期结果**：显示下单时间
- **类型**：正向

## 功能21：订单详情显示总价
- **前置条件**：用户已登录并已下单
- **操作路径**：访问订单详情页
- **预期结果**：显示订单总价
- **类型**：正向
