# 商品搜索模块需求文档

## 功能1：按关键词搜索（正向）
- **前置条件**：商品列表中存在匹配商品
- **操作路径**：首页搜索框输入"华为" → 点击搜索按钮
- **预期结果**：页面显示包含"华为"的商品（华为MateBook X Pro）
- **类型**：正向

## 功能2：按关键词搜索-无结果
- **前置条件**：不存在匹配商品
- **操作路径**：首页搜索框输入"不存在的商品xyz" → 点击搜索按钮
- **预期结果**：显示"没有找到匹配的商品"提示
- **类型**：逆向

## 功能3：按分类筛选（正向）
- **前置条件**：系统有多个分类的商品
- **操作路径**：首页 → 分类下拉选择"手机" → 点击搜索按钮
- **预期结果**：只显示手机类商品（iPhone 16 Pro, Samsung Galaxy S25, 小米14 Ultra）
- **类型**：正向

## 功能4：按分类筛选-笔记本
- **前置条件**：系统有笔记本分类商品
- **操作路径**：首页 → 分类下拉选择"笔记本" → 点击搜索按钮
- **预期结果**：只显示笔记本类商品（华为MateBook, MacBook Air, ThinkPad）
- **类型**：正向

## 功能5：关键词+分类组合搜索
- **前置条件**：存在匹配商品
- **操作路径**：搜索框输入"Apple" → 分类选择"笔记本" → 点击搜索按钮
- **预期结果**：显示Apple品牌的笔记本（MacBook Air M3）
- **类型**：正向

## 功能6：空关键词搜索
- **前置条件**：无
- **操作路径**：搜索框为空 → 分类选择"全部" → 点击搜索按钮
- **预期结果**：显示所有商品
- **类型**：边界值

## 功能7：搜索无货商品
- **前置条件**：存在库存为0的商品
- **操作路径**：搜索框输入"ThinkPad" → 点击搜索按钮
- **预期结果**：显示ThinkPad X1 Carbon，标注"无货"
- **类型**：正向

## 功能8：分类筛选-耳机（含无货商品）
- **前置条件**：耳机分类包含有货和无货商品
- **操作路径**：首页 → 分类下拉选择"耳机" → 点击搜索按钮
- **预期结果**：显示耳机类商品（Sony WH-1000XM6有货，AirPods Pro 3无货）
- **类型**：正向

## 功能9：搜索空字符串
- **前置条件**：无
- **操作路径**：搜索框输入空格 → 点击搜索按钮
- **预期结果**：显示所有商品（空格trim后为空）
- **类型**：边界值
