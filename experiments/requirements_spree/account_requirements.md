# Spree 用户账户与订单需求文档

> 来源说明：本需求文档基于 Spree Storefront README 中 Customer Account、Profile management、Order history、Address book、Saved payment methods 等功能描述，以及 `src/components/account`、`src/components/addresses` 目录整理。正式实验前需确认本地登录/注册入口、测试账户和邮箱配置。

## 功能1：用户注册
- **前置条件**：Storefront 正常访问，注册功能开启
- **操作路径**：进入注册页面 → 输入有效邮箱、密码和必填信息 → 提交注册
- **预期结果**：账户创建成功，用户进入登录状态或看到注册成功提示
- **类型**：正向

## 功能2：重复邮箱注册
- **前置条件**：系统中已存在某个邮箱账户
- **操作路径**：使用同一邮箱再次注册
- **预期结果**：系统阻止注册，提示邮箱已被使用或账户已存在
- **类型**：逆向

## 功能3：用户登录
- **前置条件**：存在有效用户账户
- **操作路径**：进入登录页面 → 输入正确邮箱和密码 → 提交登录
- **预期结果**：登录成功，页面显示账户入口或用户相关导航，受保护账户页面可访问
- **类型**：正向

## 功能4：错误密码登录
- **前置条件**：存在有效用户账户
- **操作路径**：进入登录页面 → 输入正确邮箱和错误密码 → 提交登录
- **预期结果**：登录失败，系统显示认证失败提示，不应进入账户页面
- **类型**：逆向

## 功能5：访问订单历史
- **前置条件**：用户已登录，账户中存在历史订单或无订单状态
- **操作路径**：进入账户中心 → 打开订单历史页面
- **预期结果**：若存在订单则展示订单列表、订单号、日期、状态和金额；若不存在订单则展示空状态
- **类型**：正向

## 功能6：查看订单详情
- **前置条件**：用户已登录且存在历史订单
- **操作路径**：在订单历史中点击某个订单
- **预期结果**：页面展示订单详情，包括商品清单、账单地址、配送地址、支付信息、订单总额和履约状态
- **类型**：正向

## 功能7：未登录访问账户页面
- **前置条件**：用户未登录
- **操作路径**：直接访问账户中心、订单历史或地址簿页面
- **预期结果**：系统重定向到登录页面或提示需要登录，不应泄露账户数据
- **类型**：逆向

## 功能8：新增地址簿地址
- **前置条件**：用户已登录
- **操作路径**：进入地址簿页面 → 点击新增地址 → 填写有效地址信息 → 保存
- **预期结果**：地址保存成功并显示在地址列表中
- **类型**：正向

## 功能9：编辑地址簿地址
- **前置条件**：用户已登录且地址簿中已有地址
- **操作路径**：进入地址簿页面 → 点击编辑 → 修改地址字段 → 保存
- **预期结果**：地址信息更新成功，列表显示修改后的内容
- **类型**：正向

## 功能10：删除地址簿地址
- **前置条件**：用户已登录且地址簿中已有地址
- **操作路径**：进入地址簿页面 → 点击删除地址 → 确认删除
- **预期结果**：地址从列表中移除，系统不再展示该地址
- **类型**：正向

## 功能11：保存无效地址
- **前置条件**：用户已登录并进入新增或编辑地址页面
- **操作路径**：留空必填地址字段或输入非法邮编 → 保存
- **预期结果**：系统提示字段校验错误，地址不应保存
- **类型**：边界值
