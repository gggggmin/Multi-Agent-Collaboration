# Spree 购物车需求文档

> 来源说明：本需求文档基于 Spree Storefront README 中 Shopping Cart 功能描述以及 `src/components/cart`、商品详情组件结构整理。正式实验前需根据本地页面文案与按钮选择器进行校准。

## 功能1：添加单个商品到购物车
- **前置条件**：商品可售，必要变体已选择
- **操作路径**：进入商品详情页 → 点击加入购物车按钮
- **预期结果**：商品被加入购物车，购物车抽屉或购物车页面显示该商品，数量默认为 1
- **类型**：正向

## 功能2：未选择变体时加入购物车
- **前置条件**：商品存在必选变体且尚未选择
- **操作路径**：进入商品详情页 → 不选择变体 → 点击加入购物车
- **预期结果**：系统阻止添加，提示选择变体或保持加入购物车按钮不可用
- **类型**：逆向

## 功能3：增加购物车商品数量
- **前置条件**：购物车中已有某个商品，且库存允许继续增加
- **操作路径**：打开购物车 → 点击增加数量按钮或修改数量为更大值
- **预期结果**：商品数量增加，小计、订单总价和购物车数量同步更新
- **类型**：正向

## 功能4：减少购物车商品数量
- **前置条件**：购物车中某商品数量大于 1
- **操作路径**：打开购物车 → 点击减少数量按钮或修改数量为更小值
- **预期结果**：商品数量减少，小计、订单总价和购物车数量同步更新
- **类型**：正向

## 功能5：删除购物车商品
- **前置条件**：购物车中存在商品
- **操作路径**：打开购物车 → 点击删除或移除商品按钮
- **预期结果**：该商品从购物车中移除，总价重新计算；若无其他商品，购物车显示空状态
- **类型**：正向

## 功能6：查看空购物车
- **前置条件**：购物车为空或购物车 token 不存在
- **操作路径**：打开购物车抽屉或购物车页面
- **预期结果**：页面显示空购物车状态，并提供继续购物入口
- **类型**：边界值

## 功能7：添加超过库存的商品数量
- **前置条件**：商品库存有限
- **操作路径**：反复增加购物车中同一商品数量直到超过库存限制
- **预期结果**：系统阻止超库存数量，显示库存不足、数量上限或操作失败提示
- **类型**：边界值

## 功能8：购物车状态刷新后保持
- **前置条件**：购物车中已有商品
- **操作路径**：刷新页面或跳转到其他页面后再次打开购物车
- **预期结果**：购物车商品和数量仍然保持，除非用户主动清空或 session/token 失效
- **类型**：正向

## 功能9：从购物车进入结算
- **前置条件**：购物车中至少有一个可结算商品
- **操作路径**：打开购物车 → 点击 checkout 或 proceed to checkout 按钮
- **预期结果**：跳转到结算页面，结算摘要中显示购物车商品和订单金额
- **类型**：正向
