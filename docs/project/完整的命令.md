## 三、框架各模块命令

终端 2 中执行以下命令。

### 1. RAG 知识检索

```bash
# 构建索引
python main.py rag

# 检索测试
python main.py rag -q "登录"
python main.py rag -q "购物车"
```

### 2. 多智能体博弈生成用例

```bash
# RL-AGS 自适应模式（默认，推荐）
python main.py generate -m login

# 固定轮次模式（对比实验用）
python main.py generate -m login --no-rl

# 无 Auditor 模式（消融实验）
python main.py generate -m login --no-auditor
```

支持模块: login / search / cart / checkout

### 3. 测试脚本生成

```bash
python main.py codegen -o output
```

### 4. 执行自愈（含 RL-HSS 策略选择）

```bash
# 诊断
python main.py heal output/test_login.py --dir .

# 自动修复（使用 Bandit 选择最佳策略）
python main.py heal output/test_login.py --dir . --fix
```

### 5. 训练 RL-AGS 模型

```bash
# 训练 PPO 智能体（默认 10000 步）
python main.py train-rl

# 指定训练步数
python main.py train-rl --timesteps 20000
```

训练好的模型保存在 `.cache/rl_models/ags_ppo.zip`。

### 6. 运行实验

```bash
# 完整实验（RAG + 多智能体 + 评价）
python main.py experiment --type full

# 消融实验（有/无Auditor + RL对比）
python main.py experiment --type ablation

# RL 对比实验（固定轮次 vs RL-AGS）
python main.py experiment --type rl

# 全部实验
python main.py experiment --type all
```

## 五、新增模块概览

| 模块 | 文件 | 说明 |
|------|------|------|
| RL-AGS 环境 | `framework/rl/ags_environment.py` | Gymnasium 环境，状态=5维向量，动作=继续/停止 |
| RL-AGS 训练器 | `framework/rl/ags_trainer.py` | 基于 SB3 PPO 训练智能体 |
| RL-HSS Bandit | `framework/rl/hss_bandit.py` | ε-greedy Bandit 选择修复策略 |
| AutoGen 集成 | `framework/multi_agent/base_agent.py` | 使用微软 AutoGen AssistantAgent |
| 实验出图 | `experiments/run_experiments.py` | 自动生成消融实验和 RL 对比图表 |
