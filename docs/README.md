# Documentation index

- `project/`: requirements, architecture, commands, and progress reports.
- `research/`: algorithms, experiment records, results, and next-step plans.
- `thesis/`: thesis drafts, planning material, and references.
- `proposal/`: proposal documents, defense notes, and slide outlines.
- `presentations/`: group-meeting and research presentation material.
- `references/`: university templates and source reference packages.

Office documents and presentation binaries are kept locally and ignored by Git. Their Markdown sources and outlines remain versioned.
