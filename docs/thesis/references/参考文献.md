# 参考文献

## 项目概述

本项目实现了一个**基于多智能体协同与检索增强生成（RAG）的需求驱动自动化测试生成框架**，涉及以下核心技术栈：大语言模型（LLM）、多智能体博弈、检索增强生成（RAG）、向量数据库、语义嵌入、自动化测试脚本生成与自愈。

---

## 一、大语言模型与测试用例生成

### 1.1 面向测试用例生成的大模型高效微调方法
- **作者**：曹鹏, 陈刚, 季学纯, 刘歆一, 温广琪, 杨金柱
- **期刊**：《计算机应用》, 2025, 第45卷 第3期, pp. 725-731
- **DOI**：10.11772/j.issn.1001-9081.2024111598
- **知网链接**：https://www.joca.cn/CN/article/getTxtFile.do?fileType=EndNote&id=27083
- **相关内容**：本项目中 CaseCreator 利用大语言模型根据需求文档生成测试用例，该文献提供了 LLM 在测试用例生成中的微调方法参考。

### 1.2 基于大语言模型的组件化工业软件系统测试用例生成方法

- **DOI**：10.12052/gdutxb.250017
- **知网链接**：https://xbzrb.gdut.edu.cn/article/doi/10.12052/gdutxb.250017
- **相关内容**：采用分步生成策略（测试用例生成→修正→测试代码生成），与本项目的 Creator-Auditor 博弈迭代机制思路一致。

### 1.3 基于大语言模型的故障复现测试用例生成方法
- **作者**：汪莹, 字千成, 彭鑫, 娄一翎

## 三、检索增强生成（RAG）

### 3.1 Retrieval-Augmented Test Generation: How Far Are We?
- **作者**：多位作者
- **来源**：arXiv preprint, 2024, arXiv:2409.12682
- **链接**：https://arxiv.org/abs/2409.12682
- **相关内容**：系统评估 RAG 在单元测试生成中的效果，发现基础 RAG 提升行覆盖率约 8.94%。为本项目 RAG 模块的核心参考文献。

### 3.2 LLM-based Unit Test Generation via Property Retrieval (APT)
- **作者**：多位作者
- **来源**：arXiv preprint, 2024, arXiv:2410.13542
- **链接**：https://arxiv.org/abs/2410.13542
- **相关内容**：提出基于属性的检索增强方法，将测试生成分为 Given/When/Then 三阶段，与本项目 SemanticChunker 的三元组解析设计相呼应。

### 3.3 RAG-Driven Multiple Assertions Generation with Large Language Models (ALLMAssert)
- **作者**：多位作者
- **期刊**：Empirical Software Engineering, 2025, Vol. 30(3)
- **相关内容**：利用两个 LLM 协同工作，结合 RAG 为测试方法自动生成多个断言，CodeBLEU 达 56.61%。

### 3.4 Test Suite Augmentation using Language Models - Applying RAG to Improve Robustness Verification
- **作者**：多位作者
- **来源**：HAL Science, 2024
- **链接**：https://hal.science/hal-04615832v1
- **相关内容**：使用 GPT-4 + 定制化 RAG 为安全关键系统生成测试用例，应用于 PX4 Autopilot 和 Apollo Auto 项目。

## 四、向量数据库与语义嵌入

### 4.1 Performance Analysis of Chroma, Qdrant, and Faiss Databases
- **作者**：Emir Öztürk, Altan Mesut
- **来源**：UNITECH – Selected Papers, 2024
- **DOI**：10.70456/TBRN3643
- **相关内容**：在不同规模数据集上测试 Chroma、Qdrant 和 Faiss 的插入/查询性能。本项目使用 ChromaDB 作为向量数据库存储需求文档切片。

### 4.2 Leveraging Vector Databases for Retrieval-Augmented Large Language Model Reasoning
- **作者**：Abdul Samad Mohammed, Aarthi Anbalagan, Sayantan Bhattacharyya
- **期刊**：Journal of AI-Assisted Scientific Discovery, 2024, Vol. 4(1), pp. 260-304
- **链接**：https://scienceacadpress.com/index.php/jaasd/article/view/283
- **相关内容**：探讨将 LLM 与向量数据库（含 ChromaDB）集成的检索增强推理方法，评价 ChromaDB 为"开源、灵活、适合研究型应用场景"。

### 4.3 Sentence-BERT: Sentence Embeddings using Siamese BERT-Networks
- **作者**：Nils Reimers, Iryna Gurevych
- **会议**：EMNLP 2019 / ACL 2020
- **DOI**：10.18653/v1/D19-1410
- **链接**：https://aclanthology.org/D19-1410/
- **相关内容**：提出 Sentence-BERT 用于生成语义句子嵌入。本项目使用 sentence-transformers/all-MiniLM-L6-v2 模型进行语义检索。

### 4.4 all-MiniLM-L6-v2 模型
- **来源**：Hugging Face, Sentence-Transformers 社区周（JAX/Flax 项目）
- **模型卡片**：https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2
- **训练数据来源论文**：
  - S2ORC 引用对：ACL 2020 (https://aclanthology.org/2020.acl-main.447/)
  - Reddit 对话：arXiv:1904.06472
  - MS MARCO：DOI:10.1145/3404835.3462804
  - SPECTER：ACL 2020 (https://doi.org/10.18653/v1/2020.acl-main.207)
  - SNLI：DOI:10.18653/v1/d15-1075
  - MultiNLI：DOI:10.18653/v1/n18-1101
- **相关内容**：本项目使用该模型作为默认的嵌入模型，将需求文档切片编码为 384 维稠密向量用于相似度检索。

## 五、自动化测试框架与自愈

### 5.1 Analysis of End-to-End Test Automation Tools Based on the Examples of Selenium WebDriver and Playwright
- **作者**：Beata Bylina, Agnieszka Antończak
- **会议**：19th FedCSIS, 2024, Annals of Computer Science and Information Systems, Vol. 40
- **DOI**：10.15439/2024F3747
- **链接**：https://annals-csis.org/Volume_40/drp/3747.html
- **相关内容**：比较 Selenium WebDriver 与 Playwright，发现 Playwright 在 headless 模式下执行速度更快。本项目使用 Playwright 作为测试执行引擎。

### 5.2 Exploring Browser Automation: A Comparative Study of Selenium, Cypress, Puppeteer, and Playwright
- **作者**：B. García, J. M. del Alamo, M. Leotta, F. Ricca
- **期刊**：Communications in Computer and Information Science, 2024, Vol. 2178, pp. 142-149
- **DOI**：10.1007/978-3-031-70245-7_10
- **相关内容**：四大浏览器自动化工具的架构与功能对比。

### 5.3 Self-Healing Test Automation Framework using AI and ML
- **作者**：Sutharsan Chiranjeevi Partha Saarathy, Suresh Bathrachalam, Bharath Kumar Rajendran
- **期刊**：International Journal of Strategic Management, 2024, Vol. 3(3), pp. 45-77
- **链接**：https://econpapers.repec.org/article/bduojijsm/v_3a3_3ay_3a2024_3ai_3a3_3ap_3a45-77_3aid_3a2843.htm
- **相关内容**：利用 AI/ML 技术（动态定位器、智能等待、异常检测）构建自愈测试框架。

### 5.4 Self-Healing Web Automation: An Empirical Comparison of Traditional Selenium Frameworks and Healenium Stack
- **作者**：Savi Grover, Shruthi Sepuri
- **期刊**：IJAM Journal, 2024/2025
- **链接**：https://ijamjournal.org/ijam/publication/index.php/ijam/article/view/1391
- **相关内容**：实验表明自愈可减少 40-60% 定位器失效、降低 30-50% 维护工作量。

### 5.5 Machine Learning Approaches for Auto-Repairing Test Steps in UI Automation: A Review
- **期刊**：International Journal of Engineering and Computer Science (IJECS), 2025, Vol. 14(11)
- **链接**：https://www.ijecs.in/index.php/ijecs/article/view/5299
- **相关内容**：综述基于 ML 的 UI 测试自修复方法，涵盖元素定位器修复、LLM 驱动的修复等。

### 5.6 Self-Healing Automation with Reinforcement Learning: Adaptive Test Scripts Using PPO and Dynamic XPath in Playwright
- **作者**：Sarita Gahlot, Akhil Reddy Bairi, Muthuraman Saminathan
- **期刊**：Journal of Artificial Intelligence General Science (JAIGS), 2024
- **链接**：https://econpapers.repec.org/article/dasnjaigs/v_3a5_3ay_3a2024_3ai_3a1_3ap_3a525-534_3aid_3a341.htm
- **相关内容**：利用强化学习（PPO）实现 Playwright 测试脚本自愈。
